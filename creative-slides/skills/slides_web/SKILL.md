# Presentación web

El usuario eligió **autonomía alta**: tú construyes el deck; él dirige.

- Tools: `slides_begin`, `slides_add`, `slides_finalize`, `apply_patch`.
- Artefacto: HTML Reveal, `handler=slides-html`.
- No uses `presenton_*` ni OnlyOffice para crear este deck.
- Retocar un deck ya hecho: `apply_patch` sobre `presentations/<slug>.html`.
